## このリポジトリについて

竹本隆行（tatsu456）が個人で開発している iPhone アプリの公式サイトです。
各アプリの説明、プライバシーポリシー、サポート情報を掲載しています。

あわせて、アプリを作る過程で調べたことのうち、
アプリを使わない人にも役立つ内容を記事として公開しています。
