プライバシーポリシー

ぬか床日記 / Nuka Diary（iOS）／最終更新 2026年8月16日

要点
アカウント登録もサインインもありません。 世話の記録はお使いの端末の中に保存され、開発者に送られることはありません。
外部と通信するのは次の3つだけです。 ①天気の取得（漬け時間の目安を出すため、粗くした座標を送ります）、 ②広告の表示（無料で提供するためです）、 ③iCloud への同期（お使いの端末どうしで記録をそろえるためです）。 それぞれ第2節・第3節・第7節で具体的に説明します。

1. 開発者が受け取る情報

ありません。世話の記録、漬けたもの、メモなど、 アプリに入力した内容が開発者に送られることはありません。 これらはお使いの端末の中に保存されます。 開発者は利用者のデータを預かるサーバーを持っておらず、 記録を取得・保存・閲覧する手段がありません。

2. 天気の取得について

ぬか床の発酵は気候で速さが変わるため、漬け時間の目安を出すのに天気の情報を使っています。 情報は MET Norway（ノルウェー気象研究所） の公開 API から取得しています。

送信する座標の精度

天気を問い合わせるとき、小数第2位に丸めた緯度経度（約1km四方の範囲）を MET Norway に送信します。正確な現在地は送りません。 氏名・端末ID・アカウント情報など、利用者を特定できる情報も含まれません。

端末内に控えとして残す座標は、さらに粗い小数第1位（約11km四方）です。 問い合わせは最短でも3時間おきで、それより頻繁に通信することはありません。

MET Norway の利用条件は 同機関のライセンスページ をご確認ください。

位置情報の利用は、iOS の「設定 → プライバシーとセキュリティ → 位置情報サービス」から いつでも停止できます。停止した場合、気候に応じた目安は表示されませんが、 世話の記録などその他の機能はそのまま使えます。

3. 広告SDKが収集する情報

本アプリには Google の広告サービス「Google AdMob」の SDK （Google Mobile Ads SDK）が組み込まれています。 この SDK は、広告の配信・効果測定・不具合の診断のために、 次のデータを収集する場合があります。 収集・利用するのは開発者ではなく Google です。

データ利用目的トラッキング
デバイスIDサードパーティ広告あり
広告データサードパーティ広告、アナリティクスあり
製品の操作サードパーティ広告、アナリティクスなし
パフォーマンスデータアプリの機能、アナリティクスなし
クラッシュデータアプリの機能なし
おおよその場所アプリの機能（天気の取得）なし

表の「おおよその場所」は、第2節の天気の取得に使うものです。 広告のために位置情報を渡してはいません。 ただし広告SDKは、通信時の IP アドレスから大まかな地域を独自に推定する場合があります。 これは座標の受け渡しとは別の経路です。

「クラッシュデータ」「パフォーマンスデータ」は SDK の診断に使われるもので、 開発者向けの解析ツール（Firebase Analytics、Crashlytics など）は組み込んでいません。

これらは App Store の製品ページに表示されるプライバシー情報と同じ内容です。 Google による取り扱いの詳細は Google のポリシー、 SDK の収集内容については Google の公式ドキュメント をご確認ください。

広告のトラッキングを断りたい場合

  • iOS で使われる識別子は IDFA / IDFV です。 「設定 → プライバシーとセキュリティ → トラッキング」で追跡を拒否できます
  • 「設定 → プライバシーとセキュリティ → Apple の広告」からも、 パーソナライズされた広告を制限できます
  • 広告非表示のサブスクリプションを購入すると、広告の読み込みと表示を停止します

4. サブスクリプションについて

広告非表示のサブスクリプション（No Ads Weekly）は Apple の App Store を通じて購入されます。 決済はすべて Apple が処理し、クレジットカード番号などの支払い情報が 本アプリや開発者に渡ることはありません。 アプリが受け取るのは「有効な購読があるか」という情報だけです。

5. 写真と、利用していないもの

記録には写真を添えられます。カメラでその場で撮るか、写真ライブラリから選ぶかを選べます。 取り込んだ写真は端末内にのみ保存され、開発者に送られることも、 iCloud に同期されることもありません（第7節）。 カメラと写真へのアクセスは、iOS の「設定 → プライバシーとセキュリティ」から いつでも取り消せます。

次のものは利用していません。

  • アカウント登録・サインイン
  • 開発者向けの解析ツール（Firebase Analytics、Crashlytics 等）
  • 連絡先・カレンダー・ヘルスケアへのアクセス
  • バックグラウンドでの位置追跡
  • 開発者による利用者情報の第三者への販売・提供

6. 通知

お知らせを有効にした場合、通知はすべて端末内で予約・表示されます。 外部のサーバーを経由しません。通知は端末の設定からいつでも切ることができます。

7. データの保存・iCloud 同期・削除

記録はお使いの端末内に保存されます。 アプリを削除すると、端末内の記録も一緒に消えます。 残しておきたい記録がある場合は、削除の前にご確認ください。

iCloud への同期

同じ Apple ID の端末どうしで記録をそろえるため、世話の記録・漬けたもの・メモ・アプリの設定を iCloud（キーバリューストア）に同期します。保存先はあなた自身の iCloud で、 開発者はここにアクセスできません。取り扱いは Apple の プライバシーポリシー に従います。

写真は同期しません。容量が大きいため、写真は端末の中だけに残ります。 また、天気の情報も同期の対象外です（旅先の端末に自宅の天気が出てしまうのを避けるためです）。 記録が増えて容量の上限（約900KB）を超えた場合は、同期を止めて端末内の保存だけを続けます。

端末に iCloud が設定されていない場合、同期は行われず、記録は端末の中だけに保存されます。

iCloud 側の記録を消したい場合

アプリを削除しても、iCloud に同期された記録は残ります。 同じ Apple ID の端末でアプリを入れ直すと、記録が戻ってくることがあります。 完全に消したい場合は、iOS の「設定 →（自分の名前）→ iCloud → 保存容量を管理」から 本アプリのデータを削除してください。

8. 子どものプライバシー

本アプリは特定の年齢層を対象としたものではなく、 開発者が利用者から個人情報を収集することはありません。 13歳未満の子どもから故意に情報を集めることもありません。
