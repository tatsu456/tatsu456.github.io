プライバシーポリシー

SplitBill_EX 多通貨の割り勘（iOS / Android）／最終更新 2026年8月16日

要点
アカウント登録はありません。氏名・メールアドレス・電話番号を求めることはなく、 連絡先・写真・ヘルスデータにもアクセスしません。
会計の内容は原則としてこの端末の中だけに保存されます。 ただし共有ルームを使った場合にかぎり、 その会計データが開発者の管理するサーバーに保存されます（第3節）。
また、無料で提供するために広告を表示します。 広告SDKが収集するデータは第6節に一覧で記載します。

1. このアプリが集めないもの

アカウント登録はありません。氏名・メールアドレス・電話番号を求めることはなく、 連絡先・写真・ヘルスデータにもアクセスしません。 端末の GPS による位置情報も取得しません。

2. 端末に保存されるもの

参加者名、会計の金額と内訳、精算結果、設定は、この端末の中だけに保存されます。 アプリを削除すれば、これらも消えます。

3. 共有ルームを使った場合

ルームを作成または参加すると、参加者名・会計内容・精算結果が、 開発者の管理する Firebase Realtime Database に保存され、 同じルームIDを使う人全員が閲覧・編集できます。

この仕組みには認証がありません。 ルームIDを知っている人は誰でも読み書きできるため、 ルームIDは共有したい相手にだけお伝えください。

ルームを使わなければ、会計データが端末の外に出ることはありません。

ルームのデータを削除する

アプリ内から、ご自身で削除できます。

  1. アプリを開き、設定タブへ移動します
  2. 「共有ルーム」まで進みます（ルームに参加している間だけ表示されます）
  3. 「ルームデータを削除」を選びます
  4. 確認を読み、もう一度「ルームデータを削除」を選びます

これにより、そのルームに保存されている会計・参加者名・精算結果がすべて消えます。 サーバーから完全に削除され、元に戻すことはできません。

共有ルームは参加者全員で1つの記録を共有しているため、 削除すると他のメンバーのぶんも消えます。事前にご確認ください。 なお、ご自身の端末に保存されている会計はそのまま残ります。

保存期間はとくに定めていません。ルームのデータは削除されるまで保存されます。

4. 為替レートの取得

起動時に open.er-api.com へ 通貨レートを問い合わせます。送信されるのはレートの要求だけで、 あなたの会計内容や個人情報は含まれません。

5. 開発者が受け取る情報

開発者は、共有ルームのデータ（第3節）を保管するサーバーを管理していますが、 それ以外に利用者を識別できる情報を受け取ることはありません。 広告についても、開発者が見られるのは表示回数などの合計値のみです。

6. 広告SDKが収集する情報

本アプリには Google の広告サービス「Google AdMob」の SDK （Google Mobile Ads SDK）が組み込まれています。 この SDK は、広告の配信・効果測定・不具合の診断のために、 次のデータを収集する場合があります。 収集・利用するのは開発者ではなく Google です。

データ利用目的トラッキング
デバイスIDサードパーティ広告、アナリティクス、デベロッパの広告またはマーケティングあり
おおよその場所アナリティクス、デベロッパの広告またはマーケティング、サードパーティ広告なし
製品の操作アナリティクス、サードパーティ広告、デベロッパの広告またはマーケティングなし
広告データデベロッパの広告またはマーケティング、アナリティクス、サードパーティ広告なし
クラッシュデータアナリティクスなし
パフォーマンスデータサードパーティ広告、デベロッパの広告またはマーケティング、アナリティクスなし
その他の診断データサードパーティ広告、デベロッパの広告またはマーケティング、アナリティクスなし

「おおよその場所」は、通信時の IP アドレスから推定される大まかな地域です。 端末の GPS にはアクセスしていません。 「クラッシュデータ」「パフォーマンスデータ」「その他の診断データ」は SDK の診断に使われるもので、 開発者向けの解析ツール（Firebase Analytics、Crashlytics など）は組み込んでいません。

これらは App Store の製品ページに表示されるプライバシー情報と同じ内容です。 Google による取り扱いの詳細は Google のポリシー、 SDK の収集内容については Google の公式ドキュメント をご確認ください。

広告のトラッキングを断りたい場合

  • iOS：使われる識別子は IDFA / IDFV です。 「設定 → プライバシーとセキュリティ → トラッキング」で追跡を拒否できます
  • Android：使われる識別子は広告ID（Advertising ID）です。 「設定 → プライバシー → 広告」で削除・リセットできます

EU・英国・スイスでは初回起動時に同意画面を表示します。 同意内容は設定タブの「広告のプライバシー設定」からいつでも変更できます。

広告非表示のサブスクリプションを購入すると、広告の表示と読み込みを停止します。

7. サブスクリプションの購入

課金は iOS では Apple、Android では Google が処理します。 カード番号などの支払い情報が本アプリに渡ることはなく、開発者が見ることもできません。 アプリが受け取るのは「有効な購読があるか」という情報だけです。

8. 端末のデータを削除する

アプリを削除すると、端末に保存されている会計・参加者名・精算結果・設定はすべて消えます。 共有ルームのデータは第3節の手順で別途削除してください。

9. 子どものプライバシー

本アプリは特定の年齢層を対象としたものではなく、 開発者が利用者から個人情報を収集することはありません。

10. 免責

本アプリが表示する為替レート・精算金額・手数料の計算結果は目安です。 実際の請求額はカード会社のレートや手数料の適用時点によって異なる場合があります。 最終的な精算の判断は利用者にお願いします。

11. 変更

本ポリシーを変更する場合は、このページを更新し、最終更新日を改めます。

12. お問い合わせ

本ポリシーに関するご質問は tatlink002@gmail.com までお願いします。
